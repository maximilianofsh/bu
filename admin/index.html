Repositorio
Soy funcionario: ¿cómo obtengo mi token?
  1. Pide al administrador que agregue tu usuario de GitHub en «Usuarios y permisos». Si no tienes cuenta, créala gratis en github.com.
  2. Abre este enlace: el token ya viene con el permiso correcto («public_repo»).
  3. Elige una fecha de vencimiento, presiona Generate token, cópialo y pégalo aquí.
Soy administrador del repositorio
  1. Entra a GitHub → Fine-grained tokens.
  2. En Resource owner elige la cuenta u organización dueña del repositorio: la que aparece en «Repositorio», arriba.
  3. En Repository access elige Only select repositories y marca el repositorio del sitio.
  4. En Permissions → Contents elige Read and write.
  5. Genera el token, cópialo y pégalo aquí. Guárdalo en un lugar seguro.
